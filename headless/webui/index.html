Buttons and keys

Make a button or key on a device plugged into this server send something else, such as a shortcut to whichever computer has the cursor, or one of the hotkeys above. A bound input stops doing its usual job.

DeviceInputSends

Logitech buttons

Extra buttons on Logitech devices, like the MX Master's thumb button, can be bound above like any other input. "Acts as" instead makes a button behave as another one inside the mouse itself. The mouse forgets that when it's switched off, and the server sets it again once the mouse is back.

Batteries

Battery levels of wireless devices plugged into this server. Give each one a name, for example the room it's in. Some keyboards only report their level now and then, or when it's low, so a level can stay empty for a long time.
